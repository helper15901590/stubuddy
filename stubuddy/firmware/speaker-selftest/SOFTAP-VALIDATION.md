## v0.5.4 页面与连接控制

- 历史网络、附近网络均逐行直接显示，取消下拉框；没有记录时显示空状态提示。
- 选择网络后在该行下方展开密码表单；手动添加网络为独立入口。历史区点击直接重连且始终不展开输入框；附近列表只选中并展开输入表单。
- 页面初次进入时表单隐藏，没有readonly开关或自动focus；展开后使用原生可编辑文本框，点击由浏览器自然处理键盘。
- 页面从浏览器缓存恢复时移除输入焦点；文字保留且输入框继续可编辑。
- 人工配网时不自动重连；普通有配置开机先只启动STA，连接失败才开放配网页。页面自动填充/回车/隐式提交不连接；只有显式“连接”或历史“重连”点击发出请求。
- 选中项有浅灰背景、深色左边框和勾选；历史区浅灰卡片、附近区白底并说明不同操作。
- 输入期间暂缓重建所在列表，后台扫描/轮询不会移走正在输入的文本框或丢失密码；结束输入后再更新列表。
- 连接/错误反馈同时显示在顶部和当前展开的表单中，避免长列表底部操作时看不到反馈。
- 继续使用单文件内嵌CSS/JavaScript，无外部字体、图标、图片或框架；页面小于24KiB。
- 正常手机探测GET/HEAD请求走最后注册的通配路由，返回303和配网地址，并正常排队关闭连接，保留真实错误日志。

## 配网功能

1. `stubuddy-XXXX` 设备热点改为开放热点，连接时无需密码，也不再生成或打印热点密码。
2. AP的DHCP下发本机DNS和配网页地址；DNS将A查询指向192.168.4.1，HTTP网络检测地址跳转至配网页。
3. 页面使用白底、灰色边框、深色文字与主按钮，没有外部图片、字体或脚本。
4. 保存最近成功连接的五个Wi-Fi，按最近成功使用排序；点击历史名称直接重连，密码由设备读取，不返回网页。
5. 等待手机配网和连接网络都使用两秒一周期呼吸；可恢复错误三连闪一次，两秒后恢复呼吸，严重错误持续三连闪。
6. 按住GPIO15主按键再上电，应用首次检测到按下且通过30ms消抖，立即进入重新配网，不再等待五秒。

自动弹页由手机系统网络检测决定。本固件提供自动引导机制，不能保证所有系统或关闭网络检测的手机一定弹窗。
可手动点击系统的“登录网络”提示，或在浏览器打开 `http://192.168.4.1`。
实现参考：[Espressif官方Captive Portal示例](https://github.com/espressif/esp-idf/tree/master/examples/protocols/http_server/captive_portal)。

## 首次迁移确认与保留配置

新增持久化setup_done标记。旧版只有历史配置、没有此标记时先进入人工配网，历史网络仍可点击重连；显式连接成功并保存后标记完成，后续普通启动和升级保留此状态。


直接编译和烧录即可，**不要执行 erase-flash**。旧版已保存的网络会自动出现在历史列表里。
首次连接成功后，将旧单网络记录迁移到历史列表；其余设备NVS设置不清空。
本轮热点从有密码改成无密码，手机如果仍套用旧安全配置，请在手机Wi-Fi设置中“忽略/忘记”旧stubuddy热点，再重新选择。


预期出现 `Project build complete`，随后烧录完成并进入日志；按Ctrl+]退出监视。
启动版本应为 `v0.5.4`。进入配网时关键日志为：

```text
STUBUDDY_WIFI: SETUP AP: stubuddy-XXXX
STUBUDDY_WIFI: SETUP AP AUTH: OPEN (no hotspot password)
STUBUDDY_WIFI: CAPTIVE DNS: AP-only 192.168.4.1:53
```

```text

```

应用启动本身需要时间，保持到出现该日志或配网提示音后即可松开；没有额外五秒等待。
首次未保存网络时直接配网。已完成首次配网确认的普通启动先仅以STA自动连接最近一次成功网络，不同时开放配网页；失败后进入人工配网等待。需要查看历史列表时按住上电进入配网。

## 手机配网与历史重连

1. 按住GPIO15主按键，插USB上电，出现入口日志或提示后松开。
2. 手机选择stubuddy热点，不输入热点密码，等待自动弹出白色配网页。
3. 允许保持“无互联网”的连接；没有弹窗时点“登录网络”或手动打开上述HTTP地址。
4. 页面上方“连接过的网络”显示最多五项，只有成功连接过的网络才进入历史；首次显示“还没有连接记录”。附近Wi-Fi也直接列出，点击后在该项下方展开表单。
5. 点击历史名称会直接连接；历史网络可能已经不在附近，此时连接会失败，但记录仍保留。
6. 新网络点选后在展开的密码框中主动点击输入；不会自动弹出键盘。隐藏SSID使用“手动添加网络”。历史密码变化时，从附近列表选择同名SSID再输入新密码；历史重连失败不会自动展开表单。
7. 取得IP且保存完成后，播放成功音、显示成功，约五秒后关闭热点、HTTP和DNS服务。
8. 设备进入原有按键录放。无密码家庭网络需明确勾选“这个Wi-Fi没有密码”。

家庭网络须提供2.4GHz接入，不支持需要网页登录认证的公共Wi-Fi。
设备热点无需密码，家庭Wi-Fi仍需填写自己的密码；设备开放热点仅用于本地配网，成功后自动关闭。
历史列表按SSID区分，最近成功网络排首位；重复SSID成功连接更新密码而不新增重复项；第六个新网络成功后淘汰最久未成功使用的一项。
连接失败、密码错误和仅提交请求均不新增、不替换、不淘汰历史。普通启动反复连接同一网络不重复写NVS。

## 灯光

| 状态 | LED |
| --- | --- |
| 等待配网、扫描、连接/重连中 | 两秒一周期呼吸 |
| 网络认证/连接/扫描失败 | 三连闪一次，两秒后恢复呼吸 |
| 联网完成后的普通待机 | 熄灭 |
| 本地按键录音、回放 | 常亮 |
| 音频或网络严重故障并停止 | 持续三连闪 |
| 模型等待（尚未接入） | 保留呼吸状态 |

提示音播放期间沿用播放常亮，结束后回到网络等待呼吸。网络错误优先，其次本地录放，再次网络等待。
运行中断网先尝试重连最多20秒，持续失败重新开放热点；本地录放仍可操作。
正常运行时长按按键仍为录音，最多一分钟，不会误入配网。

## 真机验收顺序

1. 先正常上电，确认旧版已存网络仍能自动连接；日志可能出现LEGACY WIFI迁移提示。
2. 按住主按键再上电，确认无额外五秒等待，热点出现且无需密码。
3. 手机忽略旧热点后重新选择，确认自动弹页或系统“登录网络”提示；若未出现，记录手机系统与手动地址是否正常。
4. 确认页面为白色极简样式，历史区显示旧网络；点击该项，应无需输入密码就能连接成功。
5. 再次进入配网，连接第二个2.4GHz网络（另一台手机热点可用）；再次进入后应看到两个历史项，点击任意一个可重连。
6. 手动连接新SSID时先输至少八位错误密码，确认错误三连闪一次、恢复呼吸、可重试，错误网络没有写入历史。
7. 如条件允许，修改一个测试网络密码后点旧历史项：确认失败后可在下方填写新密码，成功后仍只有一条该SSID记录。
8. 配网、扫描、连接时确认是呼吸；成功后待机熄灭。短录放十轮及六十秒自动回放仍按原标准检查。
9. 断电重启，确认自动连接最近一次成功网络；暂时关闭路由器，确认重连失败后热点和配网页重新可用。

连接家庭路由器时设备热点可能因共享信道变化短暂断开，可重新选择设备热点查看结果。
如果编译/烧录失败，请反馈首条错误；串口被占用时先关闭其他串口窗口。不要通过清空Flash来解决一般连接错误。

## 可选PowerShell检查（电脑已连接设备热点时）

```powershell
Resolve-DnsName -Name example.com -Server 192.168.4.1 -Type A -DnsOnly
Invoke-RestMethod -Uri 'http://192.168.4.1/api/status'
curl.exe -I 'http://192.168.4.1/generate_204'
```

预期DNS A记录为192.168.4.1；状态接口的saved_networks只有SSID、没有密码；HTTP返回303并指向 `http://192.168.4.1/`。
设备热点关闭后这些配网接口也关闭，需重新进入配网才能检查。

## 本次日志如何判断

- `hotspot-detect.html not found`：旧版借用404回调完成手机联网探测跳转，并不表示配网页文件丢失。本版改用正常GET/HEAD通配路由处理这些地址。
- `httpd_sock_err: error in recv : 104`：本机SDK errno定义为ECONNRESET，表示连接被对端重置。手机探测取消或切换页面可能产生；偶发一条、页面仍可操作时不据此判定固件故障。若持续出现且页面不可用，需连同手机系统与现象排查。
- 故意错误密码的20秒超时、错误三连闪、两秒后恢复呼吸，与设计一致。错误尝试不会覆盖成功网络历史。

## 换网络后配网IP与商用OTA

`192.168.4.1` 是本固件明确配置给设备SoftAP的本地地址，不由家庭路由器分配。
换了家庭Wi-Fi后，再进入配网并让手机连接stubuddy热点，仍可使用此地址；热点关闭后配网HTTP/DNS也关闭。
设备连接家庭网络时获得的STA地址由该路由器DHCP分配，和配网地址是两个用途。
多台设备的独立热点可各用此地址。若家庭网络碰巧也使用相同AP网段，AP/STA同时工作时的网段冲突需要在后续商用网络兼容性阶段处理。

| 用途 | 地址与条件 |
| --- | --- |
| 本地配网页 | `http://192.168.4.1/`，手机连接设备热点时使用 |
| 云端OTA检查/下载 | 自有公网HTTPS域名，所有已联网设备可以共用，不使用设备热点的私网IP |
| 可选本地手动升级 | 技术上可在同一设备IP的不同路径实现，如`/update`；本工程尚未实现此接口 |

`192.168.0.0/16` 属私网地址，不能作为跨家庭网络的统一公网OTA目的地址。
OTA方案届时按HTTPS下载和服务器证书校验实现；本次不改OTA逻辑或Flash分区。
依据：[RFC1918私网地址](https://www.rfc-editor.org/rfc/rfc1918)、[ESP-IDF HTTPS OTA](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/system/esp_https_ota.html)。
